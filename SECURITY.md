# Security

Do not open a public issue containing wallet keys, AWS credentials, API tokens,
payment authorizations, recovery bearers, or customer transaction data.

Tollary's public client is intentionally non-custodial and rejects raw private
key inputs. The hosted service must remain in testnet mode unless its separate
commercial and Mainnet readiness gates are satisfied.

For now, report a suspected vulnerability through GitHub's private security
advisory feature for this repository.
